# Knotlight

Public pages for the Android game **Knotlight: Ribbon Puzzle** (`com.ben.laama.knotlight`) by InnoCraftCode,
served by GitHub Pages at https://innocraftcode.github.io/knotlight/

- `privacy-policy/` - privacy policy (EN + FR), linked from the Play Store listing and the app
- `terms/` - terms of use (EN + FR), linked from the trader declaration in Play Console
- `app-ads.txt` - AdMob authorised sellers file

Source of these pages: the `mobile-android` workspace (`privacy-policy/knotlight/`, `terms/knotlight/`).
